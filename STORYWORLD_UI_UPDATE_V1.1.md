# Storyworld Studio V1.1 UI

This overlay upgrades the visible workflow from the original manifest-only screen to a production-oriented studio interface.

## Main route
`/storyworld`

Select a world and its available episode, then press **Build Episode**. The selection is handed to `/storyworld/generate` using query parameters.

## Workflow tabs
Story → Characters → Shots → Generate → Review → Render

## Current episode availability
Each bundled world currently exposes its pilot Episode 1. The episode selector is now present so additional episodes can be added without changing the interaction pattern.
